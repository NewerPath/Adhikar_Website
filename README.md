AADHIKAR Web is the official web portal for the Aadikar civic technology ecosystem. Built with Next.js 14, React 18, and TypeScript, it provides citizens with a streamlined interface to explore government schemes, access AI-powered guidance, and manage verification data.

Key Highlights
Universal Backend Integration: Shared Supabase database powering both the web platform and the React Native mobile app for unified data sync.

AI Assistance & Guardrails: Integrated API routes with fallback intelligence engines to provide scheme explanations and eligibility guidance.

Lightweight & High-Performance: Pure modular CSS styling with zero heavy framework bloat, optimized for low-bandwidth environments.

Responsive Civic Design: Minimalist, accessible slate/zinc UI supporting desktop and touch-first mobile viewports.

Tech Stack

Frontend: Next.js 14 (App Router), React 18, TypeScript 5.5

Backend & API: Next.js Serverless Routes, Zod Validation, Gemini API

Database & Auth: Supabase (@supabase/supabase-js)

Styling: Gluestack UI,Custom Modular CSS Architecture

Deployment: Netlify Edge Platform
